# Semantic Kernel Practice — 1-starter.py

A simple Semantic Kernel app using Google Gemini to generate recipes via a prompt-based plugin.

## Project Structure

```
semanticKernelPrac/
├── plugins/
│   ├── Cooking/
│   │   └── RecipeGenerator/
│   │       ├── skprompt.txt       # Prompt template
│   │       └── config.json        # Input variables & execution settings
│   └── Teaching/
│       ├── .env                   # API key (never commit this)
│       └── 1-starter.py           # Main script
├── venv/                          # Virtual environment
└── README.md
```

## Prerequisites

- Python 3.10+
- A Google AI Studio API key with access to `gemini-2.5-flash-lite`
  - Get one at: https://aistudio.google.com/apikey

## Setup

### 1. Create and activate virtual environment

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

### 2. Install dependencies

```powershell
.\venv\Scripts\python.exe -m pip install semantic-kernel google-genai python-dotenv
```

### 3. Set your API key

Edit `plugins/Teaching/.env`:

```
GOOGLE_API_KEY=<your_google_api_key>
```

## Run

Make sure you are in the project root and the venv is activated, then:

```powershell
python plugins/Teaching/1-starter.py
```

## Expected Output

A full step-by-step recipe for Butter Chicken generated by Gemini, e.g.:

```
Butter Chicken, also known as Murgh Makhani, is a rich and creamy Indian curry...

## Butter Chicken (Murgh Makhani)
**Yields:** 4-6 servings
...
```

## How Semantic Kernel Works Here

| Feature | Where Used |
|---|---|
| `Kernel` | Central orchestrator wiring AI + plugins |
| `add_service()` | Registers Google Gemini as the AI backend |
| `add_plugin()` | Loads the `Cooking` folder as a plugin |
| `skprompt.txt` | Natural language prompt with `{{$input}}` and `{{$format}}` variables |
| `config.json` | Declares input variables and model execution settings |
| `kernel.invoke()` | Calls `RecipeGenerator` with arguments, injects them into the prompt |

## Changing the Recipe

To generate a different recipe, edit line 16 in `1-starter.py`:

```python
result = await kernel.invoke(plugin["RecipeGenerator"], input="Biryani", format="step-by-step")
```

## Verify Available Models

To check which Gemini models are available for your API key:

```powershell
.\venv\Scripts\python.exe -c "from google import genai; client = genai.Client(api_key='<your_key>'); [print(m.name, m.supported_actions) for m in client.models.list() if 'generateContent' in (m.supported_actions or [])]"
```
